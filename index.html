Servicios implementados

Estos son los servicios configurados y las pruebas realizadas durante el proyecto.

01 · ACCESO REMOTO

SSH

OpenSSH Server permite establecer conexiones remotas cifradas para administrar un equipo.

Puerto: TCP 22

✓ Verificado localmente
02 · TRANSFERENCIA

SFTP

Transferencia de archivos mediante SSH. Se comprobó el envío y la descarga de un archivo de prueba.

Puerto: TCP 22

✓ Transferencia comprobada
03 · BASE DE DATOS

MariaDB

Gestor relacional. Se creó la base de datos proyecto_redes, una tabla usuarios y un registro de prueba.

Puerto predeterminado: TCP 3306

✓ Consultas comprobadas
04 · COMUNICACIÓN

Telnet

Se habilitó el cliente Telnet y se realizó una prueba TCP local con un servidor temporal de PowerShell.

Puerto de prueba: TCP 2323

✓ Prueba local realizada
05 · RESOLUCIÓN DE NOMBRES

DNS dinámico

Se registró un subdominio en DuckDNS y se comprobó su resolución mediante herramientas de Windows.

✓ Resolución comprobada

Arquitectura y alcance

Entorno de implementación

Sistema operativo Windows. OpenSSH, SFTP y MariaDB se configuraron y probaron en el equipo local.

Publicación web

Esta página está alojada mediante GitHub Pages y puede consultarse desde Internet sin mantener encendido el equipo de desarrollo.

Alcance de las pruebas

Las pruebas de SSH, SFTP, MariaDB y Telnet fueron locales. El registro DNS fue comprobado mediante consultas de resolución.

Nota de seguridad: la publicación de esta página no significa que los servicios SSH, SFTP o MariaDB estén expuestos públicamente. No se publican credenciales, tokens ni datos privados.

Conclusiones

El proyecto permitió implementar y comprobar servicios fundamentales de infraestructura de red. SSH facilitó el acceso remoto seguro, SFTP permitió transferir archivos mediante un canal cifrado, MariaDB permitió almacenar y consultar información estructurada, Telnet permitió observar una comunicación TCP y DuckDNS facilitó la resolución de un nombre mediante DNS dinámico.

La documentación y esta página centralizan la información técnica, los procedimientos de verificación y las evidencias del trabajo.
